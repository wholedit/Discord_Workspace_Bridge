# 4. 폰에서 쓰기

## 알림 설정

이 프로그램은 **꼭 봐야 할 것만 알림이 울리게** 만들어져 있습니다.

| 울림 | 조용히 |
|---|---|
| 봇의 답장 (작업 결과) | 진행 상태 메시지와 그 갱신 |
| 승인 요청 DM | `#control`의 일반 알림 (시작, 복구, 재시작 등) |
| `#control`의 멘션 알림 (실패, 신뢰 확인 필요, 플러그인 실패) | |

디스코드 앱에서 권장하는 설정:
- **서버 알림**: "모든 메시지" 대신 **"@mentions만"**으로 두고, 워크스페이스 채널은 채널을 길게 눌러 **알림 설정 → 모든 메시지**로 바꿉니다. 답장은 받고, 다른 채널 잡담은 조용해집니다.
- **`#control`**: "@mentions만"이면 실패 같은 중요한 알림만 울립니다.
- 봇 DM(승인 요청)은 기본으로 울립니다. 끄지 마세요.

## 채널 구성 예시

```
내 개인 서버
├ 📁 작업
│  ├ #web      ← web-bot    (C:\projects\web)
│  ├ #api      ← api-bot    (C:\projects\api)
│  └ #blog     ← blog-bot   (C:\projects\blog)
└ 📁 관리
   └ #control  ← manager-bot
```

- 봇 이름을 폴더와 맞추면 알림만 보고도 어느 워크스페이스인지 알 수 있습니다.
- 디스코드 채널 권한에서 각 봇이 **자기 채널만 보이게** 해 두면 더 안전합니다 (봇은 원래 자기 채널만 처리하지만 이중으로 막는 것).

## 자주 쓰는 흐름

- **일 시키기**: 워크스페이스 채널에 할 일을 씀 → 👀 → 진행 메시지 → 답장
- **승인**: DM 알림 → [See more]로 내용 확인 → [Allow] / [Deny]
- **잘못 시켰을 때**: `#control`에서 `/stop ws:web` (작업만 중단, 대화는 유지)
- **답이 이상하거나 맥락이 꼬였을 때**: `/new ws:web` (새 대화)
- **PC가 살아 있나**: `/ping` 또는 봇들이 온라인인지 보기 (봇이 오프라인 = 그 워크스페이스나 PC가 꺼짐)
- **전체 현황**: `/dashboard`

## 팁

- 긴 지시는 한 메시지에 모아 보내세요. 메시지를 여러 개로 나누면 각각 따로 처리될 수 있습니다.
- 결과 파일을 받고 싶으면 "결과를 파일로 첨부해줘"처럼 요청하세요.
- 사진(화면 캡처, 오류 화면)을 첨부해서 설명할 수 있습니다.
- 휴대폰을 잃어버렸다면 [5. 보안](05-security.md#폰을-잃어버렸을-때)을 보세요.
