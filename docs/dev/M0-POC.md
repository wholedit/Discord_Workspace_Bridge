# M0 검증 가이드

M0 목표: **폰만으로** 워크스페이스 두 개에 동시에 작업을 요청하고, 각 봇이 답하고, 승인 DM 버튼이 동작하고, PC에서 다시 실행해도 대화가 이어지는지 확인한다.

구조: 워크스페이스(폴더)마다 디스코드 봇 하나. 각 봇은 공식 Discord 플러그인을 단 `claude`에 연결된다. `claude`는 **내 Claude 구독으로 로그인된 상태**를 그대로 쓴다. 이 프로그램은 로그인 정보를 건드리지 않는다.

> M0에서는 설정을 터미널 질문 방식(`npm run add`)으로 한다. 같은 로직을 M3에서 웹 설정 페이지로 옮긴다.

---

## 0. 준비물 점검

```bash
npm run check
```

모두 ✓가 나와야 한다. 현재 이 PC는 아래 두 가지가 필요하다.

**Bun 설치** (공식 플러그인이 Bun으로 실행됨). PowerShell에서:
```bash
powershell -c "irm bun.sh/install.ps1 | iex"
```
설치 후 **터미널을 새로 열고** `bun --version`으로 확인한다.

**공식 Discord 플러그인 설치**: 터미널에서 `claude`를 실행한 뒤 프롬프트에 입력한다.
```
/plugin install discord@claude-plugins-official
```
- 설치 범위를 물으면 **user scope**를 고른다.
- `Marketplace "claude-plugins-official" not found`가 나오면 먼저 `/plugin marketplace add anthropics/claude-plugins-official`을 실행한다.
- 설치 후 `claude`를 종료하고 `npm run check`를 다시 실행한다.

## 1. 디스코드 준비

1. 테스트용 **개인 서버**를 하나 만든다 (+ 버튼 → 직접 만들기).
2. 텍스트 채널을 두 개 만든다. 예: `#web`, `#api`
3. 디스코드 계정에 **2단계 인증**을 켜 둔다. 이 계정이 곧 PC를 원격 조작할 권한이 된다.

## 2. 봇 두 개 만들기 (봇 하나당 약 3분)

워크스페이스마다 아래를 반복한다.

1. https://discord.com/developers/applications → **New Application** → 이름 입력 (예: `web-bot`)
2. 왼쪽 **Bot** 메뉴에서:
   - **Reset Token** → 토큰 복사 (한 번만 보임, 남에게 공유 금지)
   - **MESSAGE CONTENT INTENT** 켜기
   - **PUBLIC BOT** 끄기 (남이 내 봇을 다른 서버에 초대하지 못하게)
   - **Save Changes**

나머지(초대 링크, 채널 선택, ID 등록)는 다음 단계의 프로그램이 처리한다.

## 3. 워크스페이스 추가

```bash
npm run add
```

질문 순서:
1. **토큰 붙여 넣기** → 즉시 확인 (봇 이름 표시)
2. **Intent·Public Bot 확인** → 잘못돼 있으면 그 봇의 설정 페이지 링크를 보여 주고 다시 확인
3. **초대 링크** 표시 → 브라우저에서 열고 개인 서버 선택 → 봇이 들어오면 자동으로 다음 단계로
4. **채널 선택** (번호로 고르기)
5. **작업 폴더** 경로 입력
6. **내 계정 확인** (서버 주인을 기본값으로 제안)
7. **이름** (예: `web`)

두 번째 봇으로 한 번 더 실행해서 `#api` ↔ 다른 폴더로 추가한다. 등록 결과 확인:

```bash
npm run list
```

설정은 `C:\Users\<사용자>\.workspace-bridge\`에 저장된다. 봇마다 폴더가 따로 있고, 그 안의 `.env`에 토큰, `access.json`에 허용 목록이 들어간다.

## 4. 실행

```bash
npm run launch
```

Windows Terminal 창이 열리고 워크스페이스마다 탭이 하나씩 생긴다. 각 탭에서:
- **처음 여는 폴더면 "이 폴더를 신뢰하는지" 묻는다** → 직접 확인하고 승인한다 (폴더당 한 번).
- 시작 화면 아래에 `Channels … plugin:discord@claude-plugins-official` 안내가 보이면 연결된 것이다.
- 디스코드에서 해당 봇이 **온라인**으로 바뀐다.

> **승인 버튼이 오게 하려면**: 권한 모드가 자동(auto)이면 일부 승인을 분류기가 대신 결정해서 DM이 오지 않을 수 있다. 승인 흐름을 확인할 때는 탭에서 `Shift+Tab`으로 기본(수동 승인) 모드로 바꾼다.

이 단계에서는 터미널 탭을 켜 둔다. 창 없이 실행하고 자동으로 재시작하는 기능은 M1에서 만든다.

## 5. 폰에서 테스트 (M0 완료 체크리스트)

| # | 해볼 것 | 기대 결과 | ✓ |
|---|---|---|---|
| 1 | `#web`에 `이 폴더에 어떤 파일들이 있는지 알려줘` | 👀 리액션 → **web-bot**이 답장 | |
| 2 | 1번 진행 중에 `#api`에도 질문 | **api-bot**이 따로 답함. 두 작업이 동시에 진행되고 서로 섞이지 않음 | |
| 3 | `#web`에 `README.md를 만들고 한 줄 소개를 써줘` | **web-bot의 DM**으로 🔐 승인 요청 + [Allow] [Deny] → Allow 누르면 파일 생성 | |
| 4 | 3번을 다시 시키고 **Deny** | 파일을 만들지 않고 거부됐다고 답함 | |
| 5 | `#web`에 `방금 만든 파일 내용 다시 알려줘` | 앞 대화를 기억함 | |
| 6 | PC에서 `web` 탭을 닫고 `npm run launch -- web` | `continue last conversation`으로 다시 시작 | |
| 7 | 6번 후 `#web`에 5번처럼 이어서 질문 | 재시작 전 대화를 기억함 | |
| 8 | 연결하지 않은 채널, 또는 다른 계정으로 메시지 | 봇이 반응하지 않음 | |
| 9 | 긴 작업 요청 (예: 모든 파일 요약) | Claude가 중간 진행을 메시지 편집으로 알리고, 끝나면 새 답장(폰 알림) | |

결과를 알려 주면 M1(창 없이 실행, 자동 재시작, 진행 표시 훅)으로 넘어간다.

## 문제 해결

- **`fetch failed` / 인증서 오류 (`SELF_SIGNED_CERT_IN_CHAIN`)**: 회사망이나 보안 프로그램이 HTTPS를 검사하는 환경입니다. 이 프로그램은 npm 스크립트로 실행하면 Windows 인증서 저장소를 사용하고, `launch`도 각 워크스페이스에 같은 설정(`NODE_USE_SYSTEM_CA=1`)을 넣습니다. `npm run check`의 "Discord reachable" 항목으로 확인하세요.
- **`/discord:configure`는 쓰지 마세요**: 공식 플러그인의 기본 폴더에 토큰을 저장하기 때문에, 이후 PC에서 여는 **모든** `claude` 세션이 그 봇으로 디스코드에 접속하려고 합니다. 토큰은 `npm run add`가 워크스페이스별 폴더에 저장합니다.
- **평소 `claude`를 열면 `plugin:discord` 연결 실패가 보임**: 정상입니다. 기본 폴더에 토큰이 없어서 플러그인이 바로 종료되는 것이고, 워크스페이스로 실행할 때만 연결됩니다.
- **토큰이 노출됐을 때** (화면 공유, 스크린샷 등): 개발자 포털 → Bot → **Reset Token**으로 바로 새로 발급하고, `npm run add`로 같은 봇을 다시 등록하세요. 예전 토큰은 즉시 무효가 됩니다.

- **봇이 오프라인**: 해당 탭에서 `/mcp`를 입력해 `discord` 서버 상태를 본다. `failed`면 Bun이 설치됐는지, 탭을 새 터미널에서 열었는지 확인한다.
- **봇은 온라인인데 반응이 없음**: MESSAGE CONTENT INTENT가 켜져 있는지, 메시지를 보낸 계정이 3단계에서 등록한 계정인지, 올바른 채널인지 확인한다. 설정을 고치려면 `npm run add`로 같은 봇을 다시 추가한다.
- **승인 DM이 안 옴**: 4단계의 권한 모드 안내를 본다. 봇과 같은 서버에 있어야 DM을 받을 수 있다.
- **"blocked by org policy"**: 팀/엔터프라이즈 조직 계정이면 관리자가 채널 기능을 켜야 한다. 개인 Pro/Max 구독은 해당 없음.
- **`--continue` 후 이전 대화가 아님**: 그 폴더에서 마지막으로 쓴 대화를 이어 간다. 같은 폴더에서 PC로 직접 `claude`를 쓴 적이 있으면 그 대화가 이어질 수 있다. 새로 시작하려면 `npm run launch -- web --fresh=web`.
