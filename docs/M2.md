# M2 가이드: 관리용 봇 (`#control`)

폰의 디스코드에서 워크스페이스 상태를 보고, 재시작·작업 중단·권한 모드 변경을 하는 **관리 전용 봇**입니다.

- 관리용 봇은 **Claude와 통신하지 않습니다.** PC의 실행 관리자 안에서 돌면서 워크스페이스 프로세스만 다룹니다.
- 슬래시 명령만 쓰기 때문에 **Message Content Intent가 필요 없습니다.**
- 명령은 **등록한 내 계정만** 쓸 수 있고, 답은 **나에게만 보이는 메시지**로 옵니다.

## 1. 준비

1. 디스코드 서버에 `#control` 채널을 만듭니다. 워크스페이스 채널과는 다른 채널이어야 합니다.
2. 개발자 포털에서 **봇을 하나 더** 만듭니다: https://discord.com/developers/applications → New Application (예: `manager-bot`) → Bot → **Reset Token** → 복사
   - **PUBLIC BOT 끄기**
   - Message Content Intent는 켤 필요 없음

## 2. 등록

```bash
npm run add-manager
```

토큰 붙여 넣기(화면에 표시되지 않음) → 초대 링크로 서버에 초대 → `#control` 선택 → 내 계정 확인 순서로 진행됩니다.

등록 후 실행 관리자를 다시 시작합니다(실행 중이면 `Ctrl+C` 후 `Stopped.`를 기다린 뒤):

```bash
npm start
```

로그에 `[manager] … ready in #control; 9 slash commands registered`가 나오고, `#control`에 `🟢 Supervisor online` 메시지가 올라오면 준비된 것입니다.

## 3. 명령

워크스페이스 이름(`ws`)은 입력하면 자동완성 목록이 뜹니다.

| 명령 | 하는 일 |
|---|---|
| `/dashboard` | 모든 워크스페이스: 상태, 권한 모드, 봇 연결, 가동 시간, 재시작 횟수 |
| `/status ws:web` | 한 워크스페이스 상세 (폴더, 세션, 프로세스) |
| `/stop ws:web` | **진행 중인 작업만 중단** (Esc를 누르는 것과 같음). 세션은 계속 유지 |
| `/restart ws:web` | 다시 시작, 대화는 이어짐. `ws:all`이면 전체 |
| `/new ws:web` | 새 대화로 시작 (이전 맥락 초기화) |
| `/mode ws:web mode:manual` | 권한 모드 변경 (`auto` / `manual` / `acceptEdits` / `plan`) |
| `/logs ws:web lines:25` | 최근 터미널 화면 (10~60줄) |
| `/ping` | PC 가동 시간, CPU, 메모리, 디스크 |
| `/lockdown confirm:True` | **비상 정지:** 모든 워크스페이스 중지. 다시 켜려면 `/restart ws:all` |

## 4. 자동 알림 (`#control`)

| 상황 | 알림 | 폰 알림 |
|---|---|---|
| 실행 관리자 시작 (PC 재부팅 후 등) | 🟢 Supervisor online + 현황 | 조용히 |
| 워크스페이스 실패 (토큰 무효 등) | 🔴 이유와 해결 방법 | 울림 (멘션) |
| 폴더 신뢰 확인 필요 | 🔐 PC에서 할 명령 | 울림 |
| 디스코드 플러그인 연결 실패 | 🔴 오류 내용 | 울림 |
| 플러그인 복구 | 🟢 back online | 조용히 |
| 예기치 않은 종료 후 재시작 | 🟠 restarting | 조용히 |
| 실행 관리자 종료 | ⚪ Supervisor stopped | 조용히 |

## 5. M2 완료 체크리스트

| # | 해볼 것 | 기대 결과 | ✓ |
|---|---|---|---|
| 1 | `npm run add-manager` 후 `npm start` | `#control`에 🟢 Supervisor online + 현황 | |
| 2 | `/dashboard` | 두 워크스페이스 상태가 한눈에 보임 (나에게만 보이는 메시지) | |
| 3 | `/status ws:web` | 폴더·세션·프로세스 정보 | |
| 4 | `#web`에 긴 작업을 시키고 `/stop ws:web` | 작업이 중단되고, 이어서 질문하면 같은 대화로 답함 | |
| 5 | `/mode ws:web mode:manual` → 파일 수정 요청 → `/mode ws:web mode:auto` | 수동 모드에서 승인 DM이 옴, 되돌린 뒤엔 오지 않음 | |
| 6 | `/restart ws:api` | api가 다시 시작되고 대화는 이어짐 | |
| 7 | `/new ws:api` | api가 새 대화로 시작 (이전 내용을 기억하지 못함) | |
| 8 | `/logs ws:web` | 최근 터미널 화면이 코드 블록으로 보임 | |
| 9 | `/ping` | PC 가동 시간, CPU, 메모리, 디스크 | |
| 10 | `/lockdown confirm:True` → `/dashboard` → `/restart ws:all` | 전부 중지되고 🔒 표시 → 다시 모두 실행 | |
| 11 | 다른 계정으로 명령 시도 (가능하면) | "Not allowed" | |
| 12 | 작업 관리자에서 `claude.exe` 강제 종료 | `#control`에 🟠 restarting 알림 | |
| 13 | PC에서 `Ctrl+C` | `#control`에 ⚪ Supervisor stopped | |

## 문제 해결

- **슬래시 명령이 안 보임**: 디스코드 앱을 완전히 껐다 켜 보세요. 초대할 때 `applications.commands` 권한이 빠졌다면 `npm run add-manager`의 초대 링크로 다시 초대하세요.
- **`[manager] could not start: An invalid token`**: 관리용 봇 토큰이 틀렸거나 재발급된 것입니다. `npm run add-manager`로 다시 등록하세요.
- **"Not allowed"**: 등록할 때 지정한 계정만 쓸 수 있습니다. 다른 계정으로 바꾸려면 `npm run add-manager`를 다시 실행하세요.
- **`/stop` 후에도 작업이 계속되는 것 같음**: Esc는 진행 중인 응답을 끊지만, 이미 실행된 명령의 결과는 되돌리지 않습니다. 확실히 멈추려면 `/restart`를 쓰세요.
