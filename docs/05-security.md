# 5. 보안

이 프로그램을 쓰면 **디스코드 계정이 곧 PC를 원격 조작할 권한**이 됩니다. 그래서 기본값을 안전하게 두었습니다.

## 꼭 할 것

1. **디스코드 2단계 인증** 켜기 (사용자 설정 → 내 계정).
2. 모든 봇의 **PUBLIC BOT 끄기**. 설정 페이지가 확인합니다. 켜져 있으면 남이 링크로 내 봇을 자기 서버에 초대할 수 있습니다 (그래도 명령은 듣지 않지만, 불필요한 노출입니다).
3. **개인 서버**를 쓰고, 다른 사람을 초대하지 않기.
4. 봇 토큰은 **비밀번호처럼** 다루기. 화면 공유·스크린샷에 나오지 않게 하세요. 노출됐다면 바로 개발자 포털 → Bot → **Reset Token**, 그리고 설정 페이지에서 같은 봇을 다시 등록하세요 (예전 토큰은 즉시 무효).

## 기본으로 막혀 있는 것

| 장치 | 내용 |
|---|---|
| 허용 목록 | 각 봇은 **등록한 계정 한 명**의 메시지만 처리 (`access.json`). 다른 사람은 같은 채널에 써도 무시됨 |
| 채널 고정 | 각 봇은 **자기 채널 하나**와 **등록한 계정의 DM**만 처리. 다른 채널·다른 사람의 DM은 무시 |
| 관리 명령 | 등록한 계정만 사용 가능, 답은 나에게만 보임 |
| 권한 모드 | 기본 `auto`: 위험한 작업은 DM으로 승인 요청. 모든 확인을 건너뛰는 모드는 지원하지 않음 |
| 폴더 신뢰 | `claude`의 "이 폴더를 신뢰합니까?"에 **프로그램이 대신 답하지 않음** |
| 설정 페이지 | `127.0.0.1`(이 PC)에서만 열림. 주소의 무작위 키가 있어야 동작, 다른 웹사이트의 요청은 거절, 끝내면(또는 20분 뒤) 닫힘 |
| 토큰 저장 | `~/.workspace-bridge` 아래에만 저장. 저장소에 들어가지 않음. 설정 페이지로 다시 보내지 않음 |
| Claude 로그인 | 이 프로그램은 Claude 로그인 정보를 **읽지도, 저장하지도, 중계하지도 않음** |
| 네트워크 | PC에서 디스코드로 나가는 연결만 사용. 포트를 열 필요 없음 |

## 폰을 잃어버렸을 때

1. 다른 기기에서 디스코드에 로그인 (또는 웹 https://discord.com/app).
2. `#control`에서 **`/lockdown confirm:True`** → 모든 워크스페이스 즉시 중지.
3. 디스코드 **사용자 설정 → 기기**에서 잃어버린 폰의 세션을 로그아웃. 비밀번호도 바꾸세요.
4. 안전해지면 `/restart ws:all`로 다시 켭니다.

관리용 봇이 없다면 PC에서 `npm run stop`.

## 권한 모드 고르기

- 중요한 프로젝트, 처음 써 보는 경우: **`manual`** (모든 수정·명령을 직접 승인)
- 일상적인 작업: **`auto`** (기본)
- 코드를 읽고 계획만 받고 싶을 때: **`plan`**

`auto`에서도 분류기가 위험하다고 판단한 작업은 승인을 요청하지만, 분류기가 모든 위험을 걸러 낸다고 보장할 수는 없습니다. **중요한 데이터가 있는 폴더는 연결하지 않는 것**이 가장 안전합니다. 깃(Git)으로 관리되는 프로젝트 폴더를 권장합니다 (잘못된 변경을 되돌릴 수 있게).

## 회사 PC

- 보안 프로그램(EDR)이 서명 없는 실행 파일을 막을 수 있습니다. 이 프로그램은 PC에서 작은 도우미 두 개를 빌드합니다: `bun.exe` 래퍼(플러그인 연결 문제 우회), `awake.exe`(절전 방지). 막히면 보안 담당자에게 문의하거나 [7. 문제 해결](07-troubleshooting.md)을 보세요.
- 회사 정책상 개인 디스코드로 업무 PC를 조작하는 것이 허용되는지 먼저 확인하세요.
