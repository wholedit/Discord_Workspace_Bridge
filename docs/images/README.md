## 찍기 전에 꼭

- **봇 토큰이 보이지 않게.** 개발자 포털 화면은 Reset Token을 누르기 전 상태로 찍거나 가리세요.
- 내 디스코드 아이디·서버 이름·실제 프로젝트 폴더 경로·사용자 ID가 보이면 가리거나, 테스트용 이름(예: `web`, `C:\projects\web`)으로 찍으세요.
- 설정 페이지 주소창의 `?k=…` 키는 잘라 내세요 (그 실행에서만 쓰이지만 굳이 공개할 필요는 없음).
- 폰 화면은 세로, PC 화면은 필요한 부분만 잘라서. PNG 권장, 한 장 1MB 이하.
